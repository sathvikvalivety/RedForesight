Red Team Memory Agent technical specification

Tech stack

Language & runtime

Python 3.11 + async

LangGraph for agent orchestration and graph-based state machine
FastAPI for REST surface exposed to Splunk webhooks
asyncio throughout — MCP calls, vector DB reads, LLM calls all concurrent
LangGraphFastAPIPython 3.11

Agent LLM

Splunk hosted model

Use Splunk's hosted LLM via AI Assistant API — keeps data in-environment, no external exfil
System prompt primed as a red team operator: "You are simulating an attacker who just observed..."
Structured JSON output enforced: tactic, technique ID, probability, prerequisite conditions
Splunk hosted modelAI Assistant API

Memory layer

Dual-store memory

Episodic memory: Chroma or Qdrant vector DB, one record per past incident. Stores signal fingerprint + what actually happened next
Semantic memory: MITRE ATT&CK JSON loaded as embeddings at startup — technique descriptions, procedure examples
Recall: cosine similarity search on incoming signal embedding, top-5 retrieved, fed into LLM context window
ChromaDBsentence-transformersMITRE JSON

Splunk integration

MCP Server tools

splunk_search — run SPL queries to pull surrounding context when a signal fires
splunk_alert_create — write defender recommendations back as Splunk alerts
splunk_lookup — enrich signals with asset metadata, vulnerability scores
All tool calls through Splunk MCP Server — eligible for Best Use of Splunk MCP Server prize
Splunk MCP ServerSPL

Game tree scoring

Probability model

Each candidate next-move gets scored: p(success) = LLM prior × memory match score × asset vulnerability weight
Tree pruned to depth 3 (3 moves ahead) — beyond that uncertainty compounds too fast to be useful
Branches below p=0.15 dropped — analyst only sees actionable predictions
Bayesian weightingdepth-3 tree

Feedback loop

Self-improving memory

Analyst confirms or rejects each prediction via a lightweight Splunk dashboard widget
Confirmed predictions write a new episode to vector DB with outcome = true
Over time, recall accuracy improves for your specific environment — it learns your attacker patterns
RLHF-liteepisodic memory
